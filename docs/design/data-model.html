Data model

The seven PostgreSQL tables, how they relate, and their constraints and indexes.

The diagrams didn't load. They need an internet connection to fetch the Mermaid library. Each diagram's text source is still shown, and every table in this page works without it.

Seven PostgreSQL tables. All IDs are UUIDs, all timestamps are timestamptz in UTC, and money is stored as whole numbers in the smallest unit (paisa).

users

created_at / updated_attimestamptz

There's no sign-up endpoint. Staff accounts come from a seed script with fake data.

created_attimestamptz

Why not just use the audit log? Decisions are business data that people work with: Sita needs to read what Ram asked for. The audit log is the compliance record of who did what.

audit_logs

ColumnTypeNotes
iduuid, primary key
actor_iduuid → users, nullableEmpty means the system (the worker)
actor_rolevarcharRole at the time of the action
actionenumAPPLICATION_CREATED, APPLICATION_UPDATED, APPLICATION_SUBMITTED, REVIEWER_ASSIGNED, RISK_ASSESSMENT_COMPLETED, RISK_ASSESSMENT_FAILED, RISK_ASSESSMENT_RETRIED, DECISION_RECORDED, LOGIN_SUCCEEDED, LOGIN_FAILED, LOGOUT, REFRESH_TOKEN_REUSE_DETECTED
entity_type / entity_idvarchar / uuidWhat was acted on
metadatajsonbAlready redacted, e.g. {"from":"IN_REVIEW","to":"APPROVED"}. For edits, the names of changed fields, not their values
request_idvarcharTies the entry to one HTTP request
created_attimestamptz

Append-only, same transaction. Audit entries are never updated or deleted. Each one is written in the same database transaction as the change it records, so you can't get a change without an audit entry, or an audit entry for a change that didn't happen.
