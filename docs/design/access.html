Roles & access

Who can do what: the three roles, object-level authorization, and the error code each failed check returns.

Roles & permissions

ADMIN

Full operational access: sees every application, assigns reviewers and retries failed risk checks. Does not record decisions.

REVIEWER

Reviews applications and makes the decision, but only on applications assigned to them. Can't see any others.

SALES

Creates, edits and submits applications, but only their own. Can never approve or reject.

Authorization & error codes

Checking the role isn't enough. Every request on an application also checks who it belongs to (object-level authorization). This bug class is called IDOR / BOLA, and it's number one on the OWASP API security list.

  • SALES users only see and change applications they created.
  • REVIEWER users only see applications assigned to them, and only the assigned reviewer can decide.
  • ADMIN users see everything, but can't decide.
