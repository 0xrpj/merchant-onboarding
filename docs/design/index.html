Merchant Onboarding Platform: Design

Design of the back-office API used to onboard merchants: application lifecycle, permissions, background risk checks, data model, sensitive-data handling and concurrency.

Examples use fictional staff: Sita and Hari (SALES), Maya (ADMIN), and Ram and Gita (REVIEWER). Application 101 was created by Sita and application 102 by Hari; Ram is the reviewer assigned to 101. All names and data in this document are fictional.
